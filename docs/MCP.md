# MCP reference

Generated by `pnpm gen:mcp-docs` from the registry. Do not edit the tool entries by hand.

Endpoint: `https://tools.fabwaseem.com/mcp`. Stateless Streamable HTTP. JSON responses, no session, no API key. `POST` only. `GET` and `DELETE` return 405.

Each tool below is also `POST https://tools.fabwaseem.com/api/v1/tools/<slug>` with the same JSON input. The operation id in [https://tools.fabwaseem.com/openapi.json](https://tools.fabwaseem.com/openapi.json) is the MCP name.

Sixty calls a minute per address on `/mcp` and on `/api/v1/tools/<slug>`. A 429 includes `retry-after`. The limit reads the first `x-forwarded-for` hop, then `x-real-ip`.

A request with an `Origin` header must match the request host, `localhost`, `127.0.0.1`, or the site origin. A request with no `Origin` is allowed.

File fields take either `url` or `data`, not both. `data` is base64 or a data URI, decoded to at most 10 MB. `url` must be public `http` or `https` on port 80 or 443, with no userinfo. Local, private, link-local, and CGNAT addresses are refused, including after DNS lookup and after up to four redirects. The fetch times out after 15 seconds.

The handler validates with the input schema, runs the tool, and validates the output. A thrown error comes back as `isError: true` and a text message. It is not a successful result.

- Page: https://tools.fabwaseem.com/t/htpasswd-bcrypt
- HTTP: `POST https://tools.fabwaseem.com/api/v1/tools/htpasswd-bcrypt`
- Fetches the network: no

### Input

- `password` (string, required) — Password to hash or verify. It is used only for this call and is not stored.
- `algorithm` (`bcrypt` \| `argon2id`, optional, default `bcrypt`)
- `cost` (integer, optional, default `10`, minimum 4, maximum 12) — Bcrypt cost factor, from 4 to 12.
- `iterations` (integer, optional, default `2`, minimum 1, maximum 4)
- `memory` (integer, optional, default `8192`, minimum 8, maximum 19456) — Argon2id memory in KiB.
- `parallelism` (integer, optional, default `1`, minimum 1, maximum 2)
- `username` (string, optional, default `""`) — Optional htpasswd username. A colon is not allowed.
- `hash` (string, optional) — Existing bcrypt or argon2id hash. When set, the password is verified instead of hashed.

## `generate_keypair`

**Generate or convert a key pair**

Generate an RSA, EC, or Ed25519 key pair as PEM and JWK, or convert between PEM and JWK. The private key is returned in the result and is not stored. The page in the browser generates keys locally and does not send them.

- Page: https://tools.fabwaseem.com/t/rsa-keypair
- HTTP: `POST https://tools.fabwaseem.com/api/v1/tools/rsa-keypair`
- Fetches the network: no

### Input

- `action` (`generate` \| `to_jwk` \| `to_pem`, optional, default `generate`)
- `alg` (`RS256` \| `RS384` \| `RS512` \| `PS256` \| `ES256` \| `ES384` \| `ES512` \| `Ed25519`, optional, default `ES256`)
- `modulusLength` (`2048` or `4096`, optional, default `2048`)
- `pem` (string, optional) — SPKI or PKCS8 PEM to convert. Required for to_jwk.
- `jwk` (string, optional) — JWK JSON to convert. Required for to_pem.
